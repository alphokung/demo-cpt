เทศกาลใหม่ใน 4 ขั้น

1คัดลอกโฟลเดอร์ newyear-2570/ เป็นชื่อใหม่ เช่น songkran-2570/
2Designer คัดลอกการ์ด 8 ใบใน Figma ออกแบบใหม่ แล้ว export ลง cards/ (แปลงเป็น WebP คุณภาพ ~85)
3แก้ theme.json — ข้อความ โหมด ชื่อเลเวล สี และ active (ถ้าต้องการให้เปิด-ปิดเองตามวันที่ · ทดสอบนอกช่วงวันได้ด้วย ?fw-preview)
4ชี้หน้าเว็บไปที่ theme ใหม่: data-theme="celebrations/songkran-2570/theme.json"

ค่า data-* บนแท็ก script ยังมีผลเหนือ theme · ถ้าโหลด theme ไม่ได้ สคริปต์จะใช้ค่าเริ่มต้นแทน หน้าไม่พัง · ไฟล์ theme ต้องอยู่โดเมนเดียวกับหน้าเว็บ

เริ่มใช้งาน

ใส่บรรทัดเดียวก่อนปิด </body> ของหน้าที่ต้องการ แล้วปุ่มจะขึ้นมุมขวาล่างทันที

<script src="fireworks.js" defer></script>

ข้อกำหนด

โหลด styles.css ของโปรเจกต์ ปุ่ม การ์ด และสีทั้งหมดใช้ design token กับฟอนต์ Anuphan / ไอคอน Material Symbols จาก styles.css หน้าที่ใช้แพตเทิร์นหน้ามาตรฐานของโปรเจกต์มีครบอยู่แล้ว
ใช้ defer เสมอ สคริปต์อ่านค่าสีและหาปุ่ม “กลับขึ้นด้านบน” ตอนหน้าโหลดเสร็จ ปุ่มจุดพลุจะขยับขึ้นหนีปุ่มนั้นเองเมื่อมันโผล่
ไฟล์เดียวจบ ภาพน้องดีเด่นและไอคอนทางรัฐฝังอยู่ใน fireworks.js แล้ว ไม่ต้องคัดลอกไฟล์ภาพ ไม่มีไฟล์เสียงให้โหลด

ตัวอย่างการตั้งค่าที่ใช้บ่อย

<!-- หน้าปีใหม่: พลุอย่างเดียว -->
<script src="fireworks.js" data-modes="firework"
        data-label="สวัสดีปีใหม่ 2570" defer></script>

<!-- หน้าวาเลนไทน์: หัวใจอย่างเดียว -->
<script src="fireworks.js" data-modes="heart"
        data-label-heart="สุขสันต์วันวาเลนไทน์" defer></script>

<!-- ให้ผู้ใช้เลือกเองได้ทั้ง 3 แบบ (ค่าเริ่มต้น) -->
<script src="fireworks.js" defer></script>

<!-- ไม่ต้องการคะแนน/เสียง/คำอวยพรกลางจอ -->
<script src="fireworks.js" data-score="false" data-sound="false"
        data-greeting="false" defer></script>

โหมดที่ปล่อยได้

มี 3 โหมด เลือกได้ด้วย data-modes ถ้าใส่มากกว่าหนึ่งโหมด จะมีแถบสลับ “พลุ / โคมลอย / หัวใจ” เหนือปุ่ม ระบบจำโหมดที่ผู้ใช้เลือกไว้ล่าสุดและใช้เป็นค่าตั้งต้นครั้งถัดไป

ค่าชื่อกดหนึ่งครั้งได้อะไรเสียง
fireworkพลุพลุ 3 ลูกพุ่งขึ้นแล้วแตกหลายทรง (วงแหวน ดอกไม้ ระย้า) ใช้ไอคอนน้องดีเด่นเสียงฟิ้ว ตามด้วยเสียงตูมและประกายแตก
lanternโคมลอยโคม 4 ดวงลอยขึ้นช้า ๆ โยกไปมา เปลวไฟกะพริบ ยิ่งสูงยิ่งเล็กและจางหายเสียงระฆังใส ๆ
heartหัวใจพลุรูปหัวใจหลากสี 2 ลูก และหัวใจดวงเล็ก 12 ดวงลอยขึ้นเสียงตูมเบา กระดิ่ง และเสียงป๊อป

ตัวเลือก (แอตทริบิวต์ที่แท็ก script)

ใส่เป็น data-* บนแท็ก <script> ทั้งหมดไม่บังคับ

แอตทริบิวต์ค่าที่ใส่ได้ค่าเริ่มต้นทำอะไร
data-modesfirework,lantern,heart (คั่นด้วยจุลภาค)ครบทั้ง 3เลือกว่าหน้านี้ให้ปล่อยอะไรได้บ้าง ใส่ค่าเดียวจะซ่อนแถบสลับ
data-modefirework · lantern · heartตัวแรกใน data-modesโหมดตั้งต้นของหน้า ถ้าผู้ใช้เคยเลือกไว้แล้ว จะใช้ตามที่ผู้ใช้เลือก
data-labelข้อความสวัสดีปีใหม่ + ปี พ.ศ.ข้อความหัวการ์ดคะแนน และการ์ดทักทายของโหมดพลุ/โคมลอย
data-label-heartข้อความสุขสันต์วันวาเลนไทน์ข้อความเดียวกัน แต่สำหรับโหมดหัวใจ
data-subข้อความ · "" เพื่อซ่อนต่างกันตามโหมดบรรทัดเล็กใต้ข้อความทักทายของโหมดพลุ/โคมลอย
data-sub-heartข้อความ · "" เพื่อซ่อนส่งความรักให้คนที่คุณห่วงใยบรรทัดเล็กของโหมดหัวใจ
data-greetingfalseแสดงซ่อนการ์ดคำอวยพรกลางจอ (หน้านี้ซ่อนอยู่) ไม่กระทบข้อความบนการ์ดคะแนน
data-scorefalseแสดงปิดกล่องคะแนน เลเวล คอมโบ และปุ่มบันทึกการ์ดทั้งหมด
data-soundfalseเปิดปิดเสียงเอฟเฟกต์
data-hapticfalseเปิดปิดการสั่นของเครื่อง
data-autoplaytrueปิดปล่อยหนึ่งรอบอัตโนมัติ 0.6 วินาทีหลังโหลดหน้า (ไม่นับคะแนน และเสียงจะยังไม่ดังจนกว่าผู้ใช้จะแตะ)

JavaScript API

สคริปต์สร้างอ็อบเจกต์ window.thFireworks ใช้สั่งจากโค้ดของหน้าเอง เช่น ผูกกับปุ่มอื่นหรือจังหวะอื่นในหน้า

เมธอดทำอะไรค่าที่คืน
fire(kind?)ปล่อยหนึ่งรอบตามโหมดปัจจุบัน หรือระบุ 'firework' / 'lantern' / 'heart' (ไม่นับคะแนน)—
setMode(mode)เปลี่ยนโหมด (ต้องอยู่ใน data-modes) และจำไว้ให้ผู้ใช้—
getMode()อ่านโหมดปัจจุบัน'firework' · 'lantern' · 'heart'
getScore()อ่านคะแนนของผู้ใช้ในหน้านี้{ total, firework, lantern, heart, bestCombo }
share()เปิดหน้าต่างการ์ดคะแนนให้บันทึกรูป (เปิดได้เมื่อกดอย่างน้อย 1 ครั้ง)—

ตัวอย่าง

<!-- ปุ่มของเราเอง: กดแล้วส่งหัวใจ -->
<button onclick="thFireworks.fire('heart')">ส่งหัวใจ</button>

<script>
  // ฉลองเมื่อชำระเงินสำเร็จ
  function onPaid() { thFireworks.fire('firework'); }

  // อ่านคะแนนไปแสดง/ส่งไปเก็บเอง
  console.log(thFireworks.getScore());
</script>

คะแนน เลเวล และการ์ดแชร์

ออกแบบให้ชวนคนมากดแข่งกัน แล้วบันทึกการ์ดไปโพสต์ต่อใน social

การนับ ทุกครั้งที่กดปุ่มหลักนับ 1 คะแนน รวมทุกโหมด เก็บไว้ในหน้าเท่านั้น รีเฟรชแล้วเริ่มนับใหม่จาก 0
กล่องคะแนน เลื่อนลงมาจากด้านบนหลังกดครั้งแรก แสดงจำนวนครั้ง ตำแหน่ง แถบความคืบหน้า และ “อีกกี่ครั้ง” ถึงเลเวลถัดไป กล่องหน้าตาเดียวกันทุกเลเวล มีแค่ไอคอนเลเวลด้านซ้ายที่เปลี่ยน หายไปเองเมื่อไม่กดต่อ 3 วินาที (ไม่หายขณะเมาส์ชี้อยู่ หรือเปิดการ์ดคะแนนอยู่)
คอมโบ กดติดกันห่างไม่เกิน 0.65 วินาทีนับเป็นคอมโบ ตั้งแต่ x3 มีป้าย 🔥 ที่กล่อง ตั้งแต่ x5 มีข้อความ “+1 คอมโบ” ลอยจากปุ่ม ค่าคอมโบสูงสุดไปอยู่บนการ์ด
เลเวลอัป มีป้ายแจ้ง กล่องคะแนนสว่างวาบ สั่นเป็นจังหวะ และปล่อยของแถมอีก 2 ชุด
ภาพจาก designer (ไม่บังคับ) ใส่ใน LEVELS ของ fireworks.js ทีละเลเวล · icon: 'icons/lv4.svg' ไอคอนบนบาร์คะแนนและป้ายเลเวลอัป · card: 'cards/lv4.png' การ์ดทั้งใบที่ออกแบบใน Figma (กรอบ card/lvN) โค้ดจะวาดทับแค่น้องดีเด่น ตัวเลขคะแนน และคอมโบสูงสุดของผู้เล่น ตามช่องแดงในไฟล์ Figma · เลเวลที่ไม่ใส่จะใช้แบบที่โค้ดวาดเอง · ไฟล์ต้องอยู่โดเมนเดียวกับหน้าเว็บ
การ์ดคะแนน กดปุ่มแชร์บนกล่องคะแนน → ดูตัวอย่างการ์ดแล้วกด “บันทึกรูป” ได้ไฟล์ JPEG ขนาด 1080×1350 (ประมาณ 150KB) มีน้องดีเด่น จำนวนครั้ง ตำแหน่ง สถิติแยกโหมด คอมโบสูงสุด และไอคอนทางรัฐมุมขวาบน พื้นหลังเปลี่ยนตามเลเวล

เสียง · การสั่น · การเข้าถึง

เสียง สร้างสดด้วย Web Audio API ไม่มีไฟล์เสียง ความดังตามเครื่อง (ไม่มีปุ่มปิดเสียงในหน้า) เสียงเริ่มดังหลังผู้ใช้แตะครั้งแรกเท่านั้น (ข้อกำหนดของเบราว์เซอร์) และหยุดเมื่อสลับแท็บ บน iPhone ถ้าเปิดสวิตช์เงียบจะไม่มีเสียง · ปิดด้วย data-sound="false"
การสั่น (Haptic) Android: สั่นเมื่อกด สั่นเมื่อพลุแตก (พลุหัวใจสั่นเป็นจังหวะหัวใจเต้น) และสั่นยาวเมื่อเลเวลอัป · iPhone (Safari / Chrome): สั่นเฉพาะตอนนิ้วแตะปุ่ม เพราะ iOS ให้เว็บสั่นได้ผ่านสวิตช์ที่ผู้ใช้แตะเองเท่านั้น ต้อง iOS 18 ขึ้นไปและเปิด System Haptics · ปิดด้วย data-haptic="false"
ไม่บังหน้าจอ พลุและโคมวาดบนเลเยอร์โปร่งใสที่ไม่รับการกด ผู้ใช้กดและเลื่อนหน้าได้ตามปกติ
กดรัวได้ ไม่ซูม ปุ่มของ fireworks.js กันการซูมจากการแตะสองครั้งติดกัน แต่ไม่ได้ปิดการซูมทั้งหน้า ถ้าต้องการให้ทั้งหน้าเป็นแบบเดียวกัน ใส่ html, body { touch-action: manipulation; } ที่หน้านั้น
ลดการเคลื่อนไหว ผู้ใช้ที่เปิด prefers-reduced-motion จะเห็นพลุ โคม หัวใจ น้อยลง และไม่มีแอนิเมชันตกแต่ง
โปรแกรมอ่านหน้าจอ ปุ่ม แถบสลับโหมด และหน้าต่างการ์ดมีป้ายกำกับ ปิดหน้าต่างได้ด้วยปุ่ม Esc
